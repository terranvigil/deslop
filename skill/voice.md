# Voice profile

The fixer matches this when it writes as you. Copy it to `voice.local.md`
(gitignored) and fill that in; the skill reads `voice.local.md` when it
exists and falls back to this file.

Build it from things you wrote by hand before AI tools, a few thousand
words if you have them. Describe habits, with a short quote for each where
it helps:

- Sentence rhythm: how long your sentences run and when they get longer.
- Openers: how a document or section starts.
- Structure: prose, bullets or tables, and when you reach for each.
- Examples: how often, how concrete, how you introduce them.
- Recommendations: imperatives, "consider", or first person.
- Hedging: which hedges you use and how often.
- Explanation order: mechanics or reasons first.
- Caveats: notes, callouts, parentheticals.
- Contractions: yes or no.
- Never does: the habits you'd never write.

While this file is still the unfilled template, the skill uses its general
recipe and offers to build a profile from a sample of your writing.
